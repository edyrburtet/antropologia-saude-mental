Análise de Radicalização e Saúde Mental no Brasil

Este projeto utiliza ferramentas de Ciência de Dados para analisar o comportamento digital brasileiro. O foco é identificar como sentimentos de paranoia e desconfiança se manifestam em redes sociais.

🔍 Diagnóstico dos Dados:
Predomínio da "Mentira": A análise revelou que o termo "mentira" é o marcador de conflito mais comum, indicando uma crise de confiança institucional e social.

Visão Antropológica: O discurso não é apenas político, mas mimetiza defesas paranoides, onde o "outro" é constantemente desqualificado para validar uma visão de mundo isolada.
